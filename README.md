# The Anatomy Set

The free practice companion to *Medical Terminology* by Brian Khan Quintana, M.D.

One file, no account, no install. It opens on any phone and saves progress on the
device. Chapter one teaches the word parts the book's first chapter teaches, then
keeps them alive with spaced review.

**Live:** https://drkq.github.io/anatomy-set/

**Practice (v2.0):** https://drkq.github.io/anatomy-set/practice.html — every chapter's must-know words in
Dr. Khan Quintana's own voice, plus the book's matching, build-the-word, read-the-chart and self-check exercises.

Built for students at Southwestern College, Cuyamaca College and Palomar College.
